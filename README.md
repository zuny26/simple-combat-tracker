# Simple Combat Tracker

A lightweight D&D combat tracker for Dungeon Masters. Manage initiative, hit points, conditions, and notes, and keep track of turns and rounds in one encounter.

[Open the tracker](https://zuny26.github.io/simple-combat-tracker/)

No account needed. Your encounter is saved automatically in your browser, ready when you return on the same device and browser.

For development, use Node 24.15+ and install dependencies with `npm ci`. Run `npm run format` to format all supported repository files with Prettier, or `npm run format:check` to check formatting without changing files. Generated and ignored files are excluded. `npm run check` includes the formatting check; `npm run check:all` also builds the app and runs Chromium acceptance tests.
