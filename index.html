How to run a fight

Add everyone in the encounter, then run it round by round — the table keeps initiative order, hit points and conditions all in one place.

  1. 1Add creatures and type each one's initiative — rows sort highest-first automatically.
  2. 2Hit Start to begin; Next turn advances the marker and counts rounds.
  3. 3Log hits in Dmg / Heal and press Enter — the HP bar updates live.
